# Saidur Rahman — Full Stack Developer Portfolio

A modern, responsive, cyber-themed personal developer portfolio showcasing full-stack applications, AI systems, background, and contact details.

## 🚀 Live Demo & Pages
- **Home:** Interactive tech canvas with looping typewriter role animation & quick actions.
- **About Me (`about.html`):** Academic timeline (Primary School, High School, College), personal details, and profile portrait.
- **Projects (`projects.html`):** Featured projects (MindPulse, PDF QnA System, Student Management, Library Management) with Bento-style cards and distinct color grading.
- **Contact (`contact.html`):** Verified direct communication channels (WhatsApp, Phone, Email) and interactive messaging form.

## 🛠️ Built With
- **Frontend:** HTML5, Modern CSS3 (Vanilla CSS, Glassmorphism, Responsive Flex & Grid)
- **Logic & Effects:** Vanilla JavaScript (ES6+), Canvas Particle Network Animation, Dynamic Typewriter Engines
- **Fonts:** Poppins, Orbitron, Rajdhani

## 💻 Local Setup
1. Clone this repository:
   ```bash
   git clone <REPO_URL>
   cd portfolio
   ```
2. Run locally using Python or any static web server:
   ```bash
   python -m http.server 5000
   ```
3. Open `http://localhost:5000` in your browser.
