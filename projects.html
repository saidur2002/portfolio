01 // AI & HEALTHCARE / 2024
PERSONAL PROJECT

MindPulse — AI-Based Mental Health Early Warning System

1. Introduction

MindPulse is an advanced full-stack AI platform engineered to proactively monitor mental health patterns. By analyzing user behavioral inputs and real-time self-assessment metrics, the system calculates dynamic wellness scores (0–100) to identify early warning signs of stress and psychological fatigue before critical escalation.

2. Key Functionalities

⚡

Real-Time Wellness Scoring (0-100)

Computes a real-time wellness index applying predictive assessment algorithms on continuous behavioral logs.

🎯

Personalized Recommendation Engine

Prescribes customized mindfulness exercises, breathing routines, and daily schedules tailored to each user's dynamic score.

📊

Trend Visualization Dashboard

An interactive React dashboard equipped with time-series charts to track mental wellness trajectories over days and months.

🔒

End-to-End Encrypted Auth

Safeguards sensitive psychological data utilizing JWT session token management and military-grade AES-256 encryption.

3. Programming Languages & Tech Stack

  • Frontend: React.js, JavaScript (ES6+), HTML5, CSS3, Modern Dashboard UI
  • Backend: Python, FastAPI (High-Performance Asynchronous REST API)
  • Database: MongoDB (Flexible NoSQL document store for assessment records)
  • Security & Protocols: JWT (JSON Web Tokens), AES-256 Encryption, Axios, REST Architecture
React.js Python FastAPI MongoDB JWT Auth AES-256 REST API

4. How I Made It

ARCHITECTURE & IMPLEMENTATION SPEC

I architected MindPulse with a decoupled microservice structure. The frontend was developed in React.js to ensure instantaneous state updates, responsive data visualization, and seamless trend tracking. On the server side, Python with FastAPI processes incoming assessment payloads asynchronously, calculating wellness scores through deterministic scoring algorithms. User records are encrypted with AES-256 before persisting into MongoDB, ensuring complete confidentiality and HIPAA-compliant privacy protocols.

02 // NLP & RAG ENGINE / 2024
PERSONAL PROJECT

PDF QnA System — AI Document Intelligence Tool

1. Introduction

The PDF QnA System is an AI-powered document intelligence tool that enables users to upload PDF documents and extract knowledge on-demand through an interactive natural language chat interface, eliminating manual search through large text documents.

2. Key Functionalities

💬

Natural Language Document Q&A

Ask conversational queries in real-time across complex single or multi-page technical PDF documents.

🧠

Retrieval-Augmented Generation (RAG)

Extracts semantic text chunks and vector embeddings to ground AI responses strictly in factual source document text.

💾

Persistent Multi-Turn Chat Memory

Stores complete session histories in MongoDB for context-aware conversation continuity across browser visits.

📁

Role-Based Dashboard & File UI

Complete user authentication (login/signup) with integrated document library to upload, preview, and manage PDFs.

3. Programming Languages & Tech Stack

  • Frontend: React.js, Axios, Modern Responsive CSS
  • Backend & AI: Python, FastAPI, RAG Framework, Semantic Embedding Pipeline
  • Database: MongoDB (Session history and file reference storage)
  • Tools & Libraries: PyPDF / PDFPlumber, RESTful Endpoints, Postman
React.js Python FastAPI RAG Pipeline Vector Embeddings MongoDB Axios

4. How I Made It

RAG PIPELINE & INTEGRATION SPEC

I engineered an automated RAG (Retrieval-Augmented Generation) pipeline in Python. Uploaded PDFs are parsed, segmented into overlapping semantic chunks, and embedded into high-dimensional vector representations. When a query is received, cosine similarity scoring extracts the most relevant context and injects it into the LLM prompt to generate factual, hallucination-free answers. The interface was created in React.js with Axios handling multipart file uploads, while MongoDB maintains historical threads per user account.

03 // ENTERPRISE ERP & DBMS / 2023
ACADEMIC PROJECT

Student Management System

1. Introduction

A full-stack institutional web portal engineered to automate and digitize university student administration, grade tracking, course enrollment, and faculty evaluations under strict security protocols.

2. Key Functionalities

🛡️

Role-Based Access Control (RBAC)

Segmented permissions providing dedicated administrator controls and student-facing score & transcript views.

📝

Full Lifecycle Record CRUD

Add, edit, query, and organize academic enrollments, student profiles, and examination records seamlessly.

⚔️

SQL Injection Shielding

Server-side validation using parameterized PDO prepared statements to secure database operations against attack vectors.

⚡

Optimized Query Execution (3NF)

Database normalization and indexing ensuring sub-second record lookups even across thousands of student records.

3. Programming Languages & Tech Stack

  • Backend: PHP (OOP & Procedural Server Scripting)
  • Database: MySQL (Relational Database with 3NF Schema)
  • Frontend: HTML5, CSS3, JavaScript (Dynamic UI interaction)
  • Server Environment & Tools: Apache, XAMPP, Git, GitHub
PHP MySQL JavaScript HTML5 & CSS3 3NF Database PDO Prepared Statements XAMPP

4. How I Made It

RELATIONAL ARCHITECTURE SPECIFICATION

I structured the application following MVC architectural patterns in PHP. I architected the MySQL database applying Third Normal Form (3NF) to eliminate redundant fields and preserve relational integrity across course, enrollment, and student tables. All database interactions were executed via PDO parameterized queries to prevent SQL injection vulnerabilities, supported by responsive CSS layout for accessibility on university workstations and smartphones.

Library Management System

A digital library management solution that automates book cataloging, circulation workflows, member registrations, and issue/return tracking with intelligent duplicate-record prevention logic.

2. Key Functionalities

📚

Digital Catalog & Search

Searchable library collection supporting title, author, category, and ISBN lookups with real-time stock counters.

🔄

Circulation & Issue Automation

Automated lending workflows with scheduled return dates and member borrowing quota tracking.

⚠️

Duplicate-Record Detection

Custom verification logic that flags duplicate checkouts and restricts over-issuing beyond student permissions.

📱

Responsive Adaptive UI

Fluid cross-browser compatible interface designed for both librarians on desktops and students on mobile devices.

3. Programming Languages & Tech Stack

  • Backend: PHP (Server-side validation & workflow automation)

PHP MySQL JavaScript HTML5 / CSS3 Duplicate Detection Logic XAMPP Git

4. How I Made It

CIRCULATION ENGINE & DB SPEC

I built the platform using PHP and MySQL, focusing on robust data integrity and state tracking. Relational schemas were normalized into 3NF to avoid redundancy between transaction logs and book inventory. I engineered validation algorithms in PHP to prevent duplicate record entries and enforce borrowing caps. Dynamic frontend search was enhanced with clean JavaScript, while the UI layout was crafted with responsive CSS to support multi-device operations across the campus.
